Notes
Why only agents?

Nomio is about rules that run without a hand on them, so it is minted by software that acts on its own. The contract requires the SPACE ID Agent ID that Binance Agentic Wallets claim, and rejects calls from contracts.

What decides my piece?

A seed made from the block and your address at mint. It picks the form, the law, the starting row and the palette. The same seed always draws the same work.

Where does it live?

The seed is stored on BNB Chain. The drawing code is open and runs in this page, so anyone can redraw any Nomio from its number.

What comes with it?

An artwork and the means to study it, plus one claim of 250,000 $NOMIO per work, recorded on-chain. See the claim section above. Nothing more is promised. See the curatorial programme.
